# 任务：Nexent Demo 自然人声与清晰点击动作

> 对应清单：[`../tasks.md`](../tasks.md) R41。
> 执行者：Codex。状态：进行中（2026-09-02）。

## 背景

R40 已提供普通话旁白和两个真实 Fork 入口，但系统语音仍有明显机器感；鼠标在
目标附近移动和点击的节奏过慢，点击瞬间缺少足够清楚的视觉反馈。用户要求在不
改变 Nexent、DSH 或 Event 行为的前提下重制媒体。

## 实施范围

- 将 macOS 传统系统语音替换为自然度更高的普通话神经网络语音；不向仓库写入
  凭据、缓存或生成工具依赖。
- 精简旁白和总时长，使说明更接近真人演示节奏。
- 鼠标在关键操作前快速移动到目标，短暂停留后点击；点击使用高对比度按下态、
  中心闪光和双脉冲圆环，不能仅靠缓慢放大的单个圆圈表达。
- 明确展示聊天消息 Fork 图标、轨迹分叉点选择、轨迹 Fork 按钮和刷新按钮四个
  操作；选择值与操作结果仍来自 R40 已实际验收的浏览器状态。
- 保持 `docs/event/demos/nexent/trajectory-restore-fork-demo.mp4` 路径不变，并同步
  更新封面、章节、媒体参数、哈希和制作边界说明。
- 不修改 Nexent 本地实验分支、DSH `EventTrajectory` 或 Event 实现。

## 验收

1. 普通话音轨采用神经网络人声，语速自然、清楚，无削波和长时间空白。
2. 四个关键点击在正常播放速度下一眼可辨：目标高亮、鼠标抵达、按钮按下、双
   脉冲反馈和结果切换均有独立阶段。
3. 聊天快捷 Fork 和轨迹精确 Fork 的目标、边界与结果没有改变。
4. MP4 完整解码，视频、音频参数和关键帧检查通过。
5. README、任务清单和媒体哈希同步后才可标记完成。
