- 在 `scripts/event/demos/nexent/` 纳管视频合成脚本、旁白生成脚本、旁白文本、
  已验收的语音输入、真实浏览器截图和制作说明。
- 删除脚本中的临时目录与本机 ffmpeg 二进制硬编码；输入、输出默认相对仓库根目录，
  ffmpeg 可从 PATH 或显式参数解析。
- 已验收音频作为确定性合成输入；在线神经语音重新生成是可选步骤，不能成为本地
  重制视频的前置条件。
