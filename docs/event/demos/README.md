# Event demos

This catalog prevents publishable demos from being confused with one another.
Every demo directory must have its own README containing the same three
required metadata fields: name, content, and date. Add a new row here in the
same commit when adding a demo.

| Name | Content | Date | Directory |
| --- | --- | --- | --- |
| Nexent Event trajectory restore and fork | A local Nexent v2.5.0 browser demo of trajectory inspection, cross-process cold restore/resume, chat fork, and precise trajectory fork | 2026-09-03 | [`nexent/`](nexent/) |

The catalog date is the publication or material revision date, not the date on
which a viewer happens to open the file. Evidence screenshots belong under
`../evidence/` and must be labeled by the task or demo they support.
