# Contributing to Runfold

Runfold accepts focused issues, design discussion, tests, documentation, and
code changes that preserve the contracts and provenance recorded in this
repository.

## Before changing the repository

- Record the intended logical change in the applicable `docs/<domain>/tasks.md`
  before implementation, following [`AGENTS.md`](AGENTS.md).
- Do not edit pinned source under `third_party/`.
- Keep changes to retained DeepSeek Harness source limited to independently
  documented seams and mappings.
- Add or update verification in proportion to the change, and do not mark a task
  complete while its required checks fail.
